# Landing Page Project

## Overview
This project is a landing page for Dra. Letícia Coelho, a psychiatrist specializing in humanized and integrative treatment. The landing page is designed to provide information about her services, facilitate online consultations, and allow potential clients to contact her directly via WhatsApp.

## Files and Structure
- **index.html**: Contains the main structure of the landing page, including sections for the header, hero, services, testimonials, FAQ, and a call-to-action section. It will be updated to include WhatsApp call-to-action buttons.
  
- **styles.css**: Contains the styles for the landing page. This file will be updated to style the new WhatsApp buttons appropriately.

- **script.js**: Contains any JavaScript functionality for the landing page. This file may need to be updated if any interactive features are added for the WhatsApp buttons.

- **images/**: This directory contains images used in the landing page.
  - **dra-leticia.jpg**: Used in the about section of the landing page.
  - **dra-leticia2.JPG**: Used in the hero section of the landing page.

## Setup Instructions
1. Clone the repository or download the project files.
2. Open the project folder in your preferred code editor.
3. Open `index.html` in a web browser to view the landing page.
4. Update the `styles.css` file to customize the appearance of the landing page as needed.
5. Modify `script.js` to add any interactive features or functionality.
